# The grain ceiling is part of the sound, and stays in HQ too

The hardware plays back between 40 and 60 grains at once, which is what the
manual calls the thing that brings Clouds closer to the roots of granular
synthesis than a moving pointer through a sample. On a desktop that cap is not a
constraint — memory and CPU both say otherwise — so raising it was a live option.
We keep it: identical ceiling in Authentic and HQ, because HQ was defined as a
change of glass, not of window (ADR 0004), and density is a property of the
texture, not a quality setting.

## Consequences

- "Fast enough" has no number attached to it yet. There is no measured CPU
  budget and no instance-count target; if that changes, it changes as a stated
  target, not as a silent ceiling raise.
- Anyone tempted to add a voices control should argue against this document
  first, in the open, rather than discovering it in a changelog.
